第8章 文字列 — String と &str、そして UTF-8

C# の string は UTF-16、Rust の String は UTF-8 です。この違いのせいで「文字数の数え方」まで変わります。ここは早めに知るほど得をします。

先に答えを書きます。C# の string は UTF-16、Rust の String は UTF-8 です。

この 1 行のせいで、「文字列の長さ」の意味が変わり、 s[0] が書けなくなり、日本語や絵文字の扱いが変わります。 日本語を扱う人にとっては、早めに知るほど得をする話です。

「長さ」が 3 種類ある

実際に測った結果がこれです。

C# の Length は「文字数」ではない

C# 経験者がいちばん誤解しているのがここです。 "🦀".Length は 2 になります。 UTF-16 でサロゲートペアになるためです。

つまり s.Length の素直な対応物は Rust には無く、 「何を数えたいのか」を書かせる設計になっています。 面倒に見えますが、日本語を扱うなら結局その区別が必要になります。

数字での添字が書けない

C# なら s[0] で 1 文字取れます。Rust は禁じています。

なぜ禁じられているのか

UTF-8 では 1 文字が 1〜4 バイトです。 "こんにちは"[2] と書いたとき、 それが「3 バイト目」なのか「3 文字目」なのか決まりません。

しかも「3 バイト目」を返すとすれば、それは文字の途中を指すかもしれません。 そんな値を返しても意味がないので、Rust は最初から用意していないのです。

かわりに、何を数えたいかを書きます。

バイト位置での切り出しは panic しうる

&text[0..3] はバイト位置で切ります。 文字の途中で切ると、コンパイルは通りますが実行時に panic します。

日本語を切り出すときは、バイト数を数えるより chars() を使うほうが安全です。

String と &str

Rust には文字列の型が 2 つあります。ここは所有権の話がそのまま出てきます。

&str で引数を受けると、 String も文字列リテラルもそのまま渡せます。 &String で受けるとリテラルが渡せなくなるので、損です。

なぜ 2 つに分かれているのか

C# の string は不変で、参照型で、GC が面倒を見ます。 だから 1 つの型で済みます。

Rust には GC が無いので、 「このバイト列を誰が片付けるのか」を型で表す必要があります。 String は「私が片付けます」、 &str は「借りているだけなので片付けません」という宣言です。

文字列リテラル "あ" が &'static str なのも同じ理屈です。 実行ファイルに埋め込まれているので、確保も解放も要りません。

名前は PascalCase から snake_case になるだけで、 ほとんど推測できます。大きな違いは parse だけで、 C# の int.Parse は例外を投げますが、 Rust は Result を返します（第 11 章）。

split はコピーを作らない

"赤,青,黄".split(',') が返すのは &str の列です。 元の文字列への窓が 3 つできるだけで、文字はコピーされません。

C# の Split は新しい string の配列を作るので、 ここは Rust のほうが素直に速くなります。 そのかわり、元の文字列が生きている間しか使えません。

見た目 1 文字が 1 文字でないこと

最後にもう 1 段だけ深い話をします。 chars() で数えても、まだ「見た目の文字数」とは違うことがあります。

正確に数えたいとき

「見た目 1 文字」の単位は書記素クラスタと呼ばれます。 標準ライブラリには入っていないので、クレートを足します。

C# の StringInfo.GetTextElementEnumerator に当たるものです。 絵文字の肌色修飾や国旗を正しく 1 つと数えたい場合に必要になります。

全体を動かす

やってみよう
  1. examples/08-strings を動かして、3 つの「長さ」が食い違うことを自分の目で確認してください。
  2. let text = String::from("こんにちは"); let c = text[0]; と書いて E0277 を出してください。
  3. &text[0..2] を実行して、コンパイルは通るのに実行時に panic することを確認してください。エラーメッセージに「byte index 2 is not a char boundary」と出ます。
  4. 自分の名前を String に入れて、len() と chars().count() を比べてください。

この章のまとめ

  • Rust の String は UTF-8。C# の string は UTF-16。
  • len() はバイト数。文字数は chars().count()。
  • C# の Length は文字数ではない（絵文字は 2 になる）。
  • s[0] は書けない。何を数えたいか明示する設計。
  • バイト位置での切り出しは、文字の途中だと実行時に panic。
  • 引数は &str、構造体のフィールドは String。これが基本。
