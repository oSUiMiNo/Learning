第4章 変数と型 — 既定が不変であること

C# との最大の違いは、変数が既定で書き換えられないことです。`var` と `let` は似て見えて、態度がまるで違います。

この章は C# の知識でほとんど読み飛ばせます。 違うところだけ拾っていきましょう。

いちばん大きな違いは 1 つです。Rust の変数は、既定で書き換えられません。 C# の var と Rust の let は見た目が似ていますが、態度が正反対です。

既定が不変であること

実際にコンパイルすると、こうなります。

書き換えたいときは mut を付けます。

なぜ既定が不変なのか

C# でも「できるだけ readonly にする」のは良い習慣とされています。 Rust はそれを既定にしただけ、と考えると納得しやすいはずです。

実務上の効き方はもう少し強くて、 mut が付いている変数を探せば「書き換わる場所」が全部分かるという 読みやすさの利益があります。 さらに第 7 章の借用規則と組み合わさって、並行処理の安全性まで導きます。

シャドーイング — C# には無い書き方

Rust では同じ名前で変数を作り直せます。 これは再代入ではなく「新しい変数を作って、前のものを隠す」動作です。 型を変えても構いません。

C# だとこう書くしかない

C# はスコープ内の再宣言がエラーなので、名前を変えるしかありません。 valueText / valueNumber のように 苦しい名前が増えるのは、誰でも経験があると思います。

Rust のシャドーイングは、この 「同じものを段階的に変換していく」場面のためにあります。 mut と違って、各段階の値は不変のままです。

シャドーイングと mut を混同しないこと
mutシャドーイング
書き方let mut x = 1; x = 2;let x = 1; let x = 2;
型を変えられるか変えられない変えられる
実体同じ変数を書き換える別の変数を作る

char の違いに注意してください。 Rust の char は Unicode スカラ値 1 つで 4 バイトあるので、 '🦀' がそのまま 1 つの char に収まります。 C# の char は 2 バイトなので収まりません（第 8 章）。

暗黙の型変換が無い

C# は int から long へ黙って広げてくれますが、Rust はしません。

as は C# の unchecked((int)x) に近い動作です。 入りきらなければ上位ビットを捨てます。警告も出ません。

as は「そうしてよいと分かっている」ときだけ使い、 ふだんは into() か try_into() を選んでください。

あふれたときの挙動

C# より安全側に倒れている

C# の int.MaxValue + 1 は既定で回り込んで負の数になります （checked を書かないかぎり）。 Rust はデバッグビルドではその場で panic します。

リリースビルドでは速度のため回り込みますが、 どちらの挙動が欲しいかを明示するメソッドが用意されています。

メソッドあふれたとき
checked_addNone を返す
saturating_add上限で止まる
wrapping_add回り込む
overflowing_add結果と「あふれたか」の組を返す

金額や個数の計算では checked_* を使う習慣を付けると、 「気づかないうちに数字が壊れる」種類の不具合が消えます。

定数

const と static

const は C# の const と同じで、使う場所に埋め込まれます。 static は C# の static readonly に近く、 メモリ上に 1 か所だけ置かれます。 ふだんは const を使えば十分です。

やってみよう
  1. examples/04-variables を cargo run して、出力を上のコードと見比べてください。
  2. let fixed = 10; の下に fixed = 20; を書いて、E0384 が出ることを確認してください。
  3. let n: u8 = 300; と書くとどうなるか試してください。コンパイル時に「u8 に入らない」と怒られます。C# では実行時まで分からない種類の間違いです。

この章のまとめ

  • 既定は不変。書き換えるなら mut を付ける。
  • シャドーイング（let の再宣言）は C# に無い書き方。型を変えながら段階的に変換できる。
  • 暗黙の型変換は無い。into() が基本、as は値を壊すので慎重に。
  • あふれはデバッグビルドで panic する。checked_* で明示的に扱える。
  • char は 4 バイト。C# の 2 バイトとは別物。
