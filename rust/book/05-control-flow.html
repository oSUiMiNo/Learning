この章も C# の知識でほぼ読めます。覚えるのは 1 つの考え方だけです。

Rust ではほとんどのものが「式」です。 つまり値を返します。if も match も loop も、 ブロックそれ自体も値になります。 C# の式形式メンバー（=>）やスイッチ式が好きな人には、たぶん気持ちのいい話です。

if が値を返す

var greeting = hour < 12 ? "おはよう" : "こんにちは";
let greeting = if hour < 12 { "おはよう" } else { "こんにちは" };
三項演算子は無い

Rust に ? : はありません。if が式なので要らないからです。 ? という記号は別の意味（エラーの伝播、第 11 章）に使われています。

両方の枝が同じ型でなければならない

if が値を返すということは、どの枝も同じ型を返す必要があるということです。

let value = if flag { 5 } else { "five" };

また else を省くと、その枝は () を返すことになります。 値として使いたい if には else が必須です。

条件には bool しか書けない

0 や null は偽にならない

C# でも if (0) は書けませんが、 JavaScript や C から来た感覚だと if (count) と書きたくなることがあります。 Rust はこれを許しません。

if count != 0 { } // ○ if !list.is_empty() { } // ○

if x = 5 のような代入の書き間違いも、 bool でないので必ずコンパイルエラーになります。

ループの 3 種類

Rust意味C# なら
loop { }無限ループ。break で抜けるwhile (true)
while cond { }条件付きループwhile
for x in iter { }反復子をなめるforeach
C 風の for は無い

for (int i = 0; i < n; i++) に当たる構文はありません。 for は必ず「何かをなめる」形です。

for i in 0..n { } // 0 から n-1 まで（C# の for と同じ範囲） for i in 0..=n { } // 0 から n まで（= が付くと終端を含む） for i in (0..n).rev() { } // 逆順 for i in (0..n).step_by(2) { } // 2 つ飛ばし

.. が終端を含まず、..= が含みます。 この 1 文字を落とすのは、Rust で最もよくある間取り違えです。

loop は値を返せる

これは C# に対応するものがない、便利な書き方です。 break に値を付けると、それが loop 式の値になります。

let mut n = 1; let first_over_100 = loop { n *= 3; if n > 100 { break n; // これが loop の値になる } };
C# なら変数を外に用意する
int n = 1; int firstOver100 = 0; while (true) { n *= 3; if (n > 100) { firstOver100 = n; break; } }

firstOver100 を先に宣言して仮の値を入れておく必要があり、 「初期値の 0 は意味がない値だ」という気持ち悪さが残ります。 Rust の loop 式はそれを解消します。

ラベル付き break

入れ子のループから一気に抜けられます。C# の goto の代わりです。

'outer: for a in 1..=3 { for b in 1..=3 { if a * b >= 6 { break 'outer; } } }

ラベルは ' で始まります。 ライフタイム（第 15 章）と同じ記号ですが、別のものです。

match — スイッチ式の強化版

C# のスイッチ式との対応
var label = n switch { 0 => "ゼロ", 1 => "ひとつ", >= 2 and <= 9 => "一桁", _ => "二桁以上" };
let label = match n { 0 => "ゼロ", 1 => "ひとつ", 2..=9 => "一桁", _ => "二桁以上", };

ほとんど同じです。違いは Rust の match は網羅性を強制することです。 C# のスイッチ式も網羅していないと警告が出ますが、 Rust はエラーとしてビルドを止めます。 列挙型と組み合わせたときの効き方は第 10 章で扱います。

ブロックも式

波括弧のかたまりも値になります。 「計算に使う一時変数をスコープに閉じ込めたい」ときに便利です。

let computed = { let base = 10; base * base // これがブロックの値 }; // base はここでは見えない
式と文の区別

セミコロンには「式を文にする」働きがあります。 文は値を返さない（正確には () を返す）ので、次の 2 つは違うものです。

書き方ブロックの値
{ 5 }5
{ 5; }()

「型が合わない」と言われたら、まず末尾のセミコロンを疑ってください。 これは Rust を書きはじめた人が最もよく踏む間違いです。

この章のまとめ

  • if・match・loop・ブロックはすべて式。値を返す。
  • 三項演算子は無い。if が式なので要らない。
  • 条件には bool しか書けない。
  • C 風の for は無い。.. は終端を含まず、..= は含む。
  • break 値 で loop から値を返せる。C# に対応するものはない。
  • 末尾のセミコロンの有無で戻り値が変わる。型エラーの原因はまずここ。
